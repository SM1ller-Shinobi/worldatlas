# Атлас миров

Локальное приложение для разработки вымышленных вселенных, сюжетов игр, книг и других историй. Все данные находятся в выбранной вами папке. Регистрация, сервер в интернете и сторонние Python-пакеты не нужны.

## Возможности

- Сюжетные арки, главы, эпизоды и сцены с вложенностью и порядком.
- Карточки персонажей, мест, предметов, фракций, правил мира и событий хронологии. Раздел «Другое» подходит для народов, существ, языков, обычаев и любых новых понятий.
- Стандартные и собственные поля, метки, изображения и связи между записями.
- Новые изображения загружаются в PNG (до 12 МБ). В настройках приложения можно включить «Аватары»: тогда изображение записи появится в отдельной рамке слева от редактора на широком экране. Без изображения или с выключенной настройкой редактор выглядит как раньше. Старые изображения JPEG, WebP и GIF продолжают отображаться.
- Большое текстовое поле с Markdown для подробных описаний и сценариев.
- Поиск по названиям и меткам, обзор проекта, корзина с восстановлением.
- Страница «Настройки проекта»: название, описание, общий жанр (готовый или свой), формат и атмосфера мира. При создании мира она открывается первой; все поля необязательны.
- Кнопка ⚙ внизу слева открывает настройки приложения: базовое или средневековое фэнтезийное оформление. Выбранная тема действует для всех миров и сохраняется после перезапуска.
- Импорт `.md`/`.txt` как новой записи; файл целиком становится её описанием.
- Автосохранение, проверка конфликтов с внешними правками, история прежних версий и ZIP-копия проекта.

## Запуск на Windows

Нужен **Python 3.10 или новее**. Проверено на Python 3.14.7 в Windows.

1. Дважды щёлкните `launch.pyw`. Откроется браузер с приложением.
2. Если ассоциация `.pyw` не настроена, запустите `run.bat` или выполните `py -3 -m worldatlas.server` из этой папки.
3. Выберите папку мира. В существующей папке проекта он откроется; в новой папке появится новый проект. На странице «Настройки проекта» укажите общую информацию или оставьте поля пустыми и нажмите «Сохранить и перейти к миру».

При необходимости можно сразу открыть известную папку:

```powershell
py -3 -m worldatlas.server --project "C:\Мои миры\Хроники Прилива"
```

Приложение запускает небольшой сервер **только на `127.0.0.1`** со случайным портом. Пока оно открыто, браузер общается с ним локально. Кнопка «Закрыть приложение» завершает сервер. Если запускали `run.bat`, можно также нажать Ctrl+C в его окне.

Выбор оформления и переключатель аватаров хранятся отдельно от папок миров в `%LOCALAPPDATA%\WorldAtlas\settings.json`. Удаление этого файла возвращает базовую тему и выключает аватары.

## Первые шаги

1. Создайте сюжетную арку в разделе **Сюжет**. Для главы или сцены укажите родительскую запись в поле **Внутри** и число в поле **Порядок**.
2. Добавьте персонажей и места. Заполните предложенные поля или создайте собственные.
3. Свяжите сюжетную запись с персонажами, местами и предметами через блок **Связи**.
4. Пишите подробный текст в разделе **Подробное описание**. Markdown сохраняется как исходный текст в файле записи.
5. Для существующего дизайн-документа используйте **Импорт Markdown**. Импорт создаёт одну запись и не изменяет исходный файл. Большой документ позже можно разделить на главы и карточки.

## Файлы проекта

```text
Моя вселенная/
  worldatlas.json          # паспорт проекта
  WORLDATLAS_INDEX.md      # автоматически обновляемое оглавление
  stories/                 # сюжетные записи
  characters/              # персонажи
  places/                  # места
  items/                   # предметы
  factions/                # фракции
  lore/                    # устройство мира
  events/                  # хронология
  other/                   # другие понятия мира
  assets/                  # копии добавленных изображений
  .worldatlas/
    cache.json              # пересоздаваемый быстрый индекс
    history/               # прежние версии изменённых записей
    backups/               # ZIP-копии по кнопке
```

Каждая карточка — отдельный `.md` файл. В начале находится JSON-блок метаданных между строками `---`; после него — заголовок и обычный Markdown-текст. Это одновременно документация для чтения и источник данных приложения. Файлы можно редактировать другим текстовым редактором: при повторном открытии проекта изменения загрузятся. Если файл изменился, пока карточка открыта в приложении, сохранение остановится и предложит скачать черновик перед загрузкой новой версии.

`WORLDATLAS_INDEX.md` создаётся автоматически и перезаписывается при изменениях. Изменять его вручную не нужно. Нечитаемые карточки не удаляются: приложение показывает предупреждение и оставляет файлы на месте.

Для быстрого открытия приложение хранит перечень карточек в `.worldatlas/cache.json`. При открытии оно проверяет даты и размеры файлов и перечитывает изменённые. Кэш можно удалить при закрытом приложении: при следующем запуске он будет построен заново из Markdown-файлов.

## Сохранность данных

- Изменения сохраняются после короткой паузы набора текста (около 0,9 секунды); **Ctrl+S** сохраняет сразу. При попытке закрыть вкладку с несохранённым текстом браузер предупреждает.
- Новая версия файла сначала записывается во временный файл, затем атомарно заменяет старую.
- Перед изменением старая версия попадает в `.worldatlas/history/`; сохраняются последние 30 версий каждого файла.
- «В корзину» скрывает запись из оглавления, но оставляет сам файл до восстановления.
- Кнопка **Резервная копия** создаёт ZIP в `.worldatlas/backups/`. Чтобы восстановить проект, закройте приложение, распакуйте ZIP в отдельную папку и откройте её как проект.

Рекомендуется также копировать всю папку мира на другой диск или в ваше обычное хранилище резервных копий. ZIP-копии из приложения создаются по нажатию кнопки, а не по расписанию.

## Разработка

Приложение использует стандартную библиотеку Python: `http.server` для локального интерфейса, `tkinter` для системного выбора папки, JSON и Markdown-файлы для хранения. Интерфейс написан на HTML, CSS и JavaScript; сеть и CDN ему не нужны.

```powershell
py -3 -m unittest discover -s tests -v
py -3 -m py_compile worldatlas\storage.py worldatlas\server.py
```

Подробности формата и правил сохранения — в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).
