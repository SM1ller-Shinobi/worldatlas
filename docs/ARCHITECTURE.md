# Устройство проекта

## Источник данных

`worldatlas.json` хранит название, описание, жанр, формат, атмосферу мира, версию формата и время изменения. Поле `setup_complete` отмечает сохранение первого экрана настроек; у старых проектов его нет, и они открываются сразу на обзоре. Пустое название заменяется именем папки проекта. Другие общие поля необязательны. Файлы `stories/<uuid>.md`, `characters/<uuid>.md` и других разделов содержат отдельные записи. Их имена не зависят от заголовка, поэтому переименование карточки не ломает ссылки.

Формат записи:

```markdown
---
{
  "id": "<32 шестнадцатеричных символа>",
  "kind": "character",
  "schema": 2,
  "status": "Черновик",
  "tags": ["Тидхавен"],
  "fields": {"role": "Главный герой"},
  "links": [],
  "parent_id": null,
  "order": 0,
  "image": null,
  "created_at": "2026-11-06T00:00:00+00:00",
  "updated_at": "2026-11-06T00:00:00+00:00",
  "deleted": false
}
---

# Кэриан

Подробное описание в Markdown.
```

JSON в начале — совместимый с YAML 1.2 набор метаданных, но приложение читает его стандартным JSON-парсером. Поля можно менять снаружи, сохраняя правильный JSON и неизменными `id`/`kind`. Заголовок `#` после второго `---` задаёт название карточки; остальной текст редактируется свободно. Старые карточки с названием в JSON-блоке продолжают читаться.

## Сохранение и конфликты

Сервер возвращает SHA-256 содержимого каждого файла как `revision`. Клиент отправляет его обратно при записи. Если файл изменился с момента чтения, сервер отвечает `409` и не перезаписывает внешнюю версию. Интерфейс оставляет текст в редакторе и предлагает скачать черновик.

Каждая запись проходит валидацию: тип раздела, размер текста, имена связей, допустимый файл изображения, отсутствие циклов в сюжетной иерархии. Новые изображения принимаются в PNG размером до 12 МБ; в проект кладётся копия файла. Исходное изображение не меняется. Ранее добавленные JPEG, WebP и GIF остаются читаемыми.

Перед заменой карточки или паспорта проекта старая версия копируется в `.worldatlas/history/`. Затем новый файл записывается во временный файл в той же папке, сбрасывается на диск и заменяет прежний через `os.replace`. После записи обновляется `WORLDATLAS_INDEX.md`.

Для списка карточек используется удаляемый кэш `.worldatlas/cache.json`: при чтении проекта сравниваются время изменения и размер каждого Markdown-файла. Изменённый или новый файл читается заново; пропавший исчезает из кэша. При прямом открытии и сохранении карточки всегда читается сам Markdown-файл и сравнивается SHA-256, поэтому устаревший кэш не может разрешить перезапись внешней правки.

## Локальный интерфейс

Python запускает `ThreadingHTTPServer` на `127.0.0.1` со случайным портом. Изменяющие запросы требуют случайный токен текущего запуска. Токен находится только на странице, выданной этим сервером. Статические файлы интерфейса поставляются вместе с приложением; внешние скрипты и шрифты не загружаются.

Папка выбирается системным диалогом `tkinter` в отдельном процессе или вводится вручную. Последние открытые папки хранятся отдельно в `%LOCALAPPDATA%\WorldAtlas\recent.json`. Тема и переключатель аватаров хранятся в `%LOCALAPPDATA%\WorldAtlas\settings.json` и не зависят от открытого мира. Файл настроек записывается атомарно; сервер проверяет допустимые значения `modern` и `fantasy` и булево значение `avatars_enabled`. В старых файлах настроек отсутствие `avatars_enabled` означает «выключено».
